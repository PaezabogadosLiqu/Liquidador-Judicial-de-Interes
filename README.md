# Liquidador-Judicial-de-Interes
Herramienta automatizada para liquidación de créditos en procesos judiciales colombianos.  Calcula intereses civiles y comerciales (DTF) con precisión, aplicando abonos, agencias y costas.  Genera reportes automáticos en Google Sheets.

# ⚖️ Liquidador Judicial Pro

Herramienta automatizada para liquidación de créditos en procesos judicales colombianos.

## 🎯 Características

- ✅ Cálculo automático de **DTF** desde datos.gov.co (Superfinanciera)
- ✅ Soporte para intereses **CIVIL** (6% fijo) y **COMERCIAL** (DTF variable)
- ✅ Aplicación correcta de abonos (capital e intereses)
- ✅ Generación automática de liquidaciones en Google Sheets
- ✅ Interfaz web basada en Google Apps Script

## 💼 Casos de Uso

- Ejecutivos hipotecarios
- Demandas de cumplimiento de obligaciones dinerarias

## 🚀 Quick Start

1. Abre Google Apps Script
2. Copia `Code.gs` y `tasas.gs`
3. Conecta con tu Google Sheet para tasas DTF
4. Despliega como web app

## ⚙️ Stack Técnico

- **Backend:** Google Apps Script
- **Frontend:** HTML/CSS/JavaScript
- **Base de datos:** Google Sheets
- **API de tasas:** Datos.gov.co (Superfinanciera)
